追问方向与写法：
- prerequisite：指出回答里的错误点，先问更基础的原理，帮候选人把地基补上。
- verification：回答与简历有冲突，请候选人澄清哪个是真的、当时具体怎么做的。
- metrics：回答太笼统，追问具体的量级、基线、口径或结果数字。
- boundary：这是候选人没有经验的缺口题，追问「没有这个条件时你原来怎么解决」「如果换成它，你原方案哪里会失效」。

规则：
1. 一次只问一个问题。
2. 必须基于给定的题目与回答，不得引入新的事实。
3. 不要给答案，不要安慰，不要评分。
